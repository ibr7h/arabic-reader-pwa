# معمل اللغات العربية التفاعلي — PWA

نسخة معاد تنظيمها من النموذج الأحادي، مع إصلاحات المرحلة الأولى.

## ما تم إنجازه
- إصلاح تجزئة الحرف العربي مع حركاته باستخدام `Intl.Segmenter` مع fallback.
- إصلاح قاعدة السكون والمد في التحليل الديناميكي.
- القراءة الهرمية الصوتية أصبحت تعتمد نهاية النطق بدل مؤقتات ثابتة.
- حفظ رسم السبورة عند تغيير الحجم.
- السماح بتكبير الصفحة على الهاتف.
- فصل CSS وJavaScript عن HTML.
- إزالة الاعتماد على Tailwind CDN وTone.js وCanvas Confetti.
- Tailwind CSS مبني محلياً.
- Web Audio محلي للمؤثرات الصوتية، وConfetti محلي خفيف.
- Manifest + Service Worker + أيقونات PWA.
- اختبار تلقائي لمحرك العربية.

## التشغيل محلياً
شغّل خادماً محلياً داخل مجلد المشروع، مثلاً:

```bash
python3 -m http.server 8080
```
ثم افتح `http://localhost:8080`.

> ملاحظة: Google Fonts بقيت تحسيناً اختيارياً. إذا لم يتوفر الإنترنت يستخدم التطبيق خطوط fallback ولا تتعطل الوظائف الأساسية.

## إضافات v3
- اختيار ترتيب الحروف بين **كتاب لغتي** و**الترتيب الهجائي**.
- السبورة المغناطيسية تدعم عدة كلمات مكتملة في الوقت نفسه.
- تحديد الكل وتحريك/حذف المجموعة المحددة.
- الحركات قابلة للتبديل والإزالة مع تموضع بصري مستقل.
- قلم السبورة يستخدم Pointer Events وتنعيم منحنيات ودقة شاشة مرتفعة.

## v4 additions
- اضغط على أي مكان فارغ في السبورة المغناطيسية لإلغاء التحديد.
- الضغط على حرف من كلمة مكتملة يحدد الكلمة كاملة لتحريكها أو تكبيرها/تصغيرها كمجموعة، مع إبقاء الحرف المضغوط نشطًا لتغيير حركته.
- دعم صريح لأشكال الألف: **ا، أ، إ، آ**.
- دبدوب التحليل يحافظ على هيئة الحرف حسب موقعه الحقيقي في الكلمة.
- تحسين قلم السبورة للجوال والتابلت.
- تكبير واضح للتشكيل على السبورة.
- تكبير وتصغير الحروف المحددة من 65% إلى 180%.
