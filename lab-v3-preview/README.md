# معاينة معمل اللغات العربية — v3

هذه نسخة تجريبية منشورة للاختبار، وليست إصدارًا نهائيًا.

## حالة النسخة
- تتضمن تحسين سلاسة قلم السبورة والتراجع والتحكم في السماكة.
- تتضمن ترتيب الحروف أبجديًا أو بحسب تسلسل كتاب لغتي.
- تدعم تعدد الكلمات على السبورة المغناطيسية وتحديد الكل وتحريك المجموعة.
- تسمح باستبدال الحركة على الحرف وتموضع الحركات بصريًا.
- ما زالت هناك ملاحظات قيد المراجعة قبل اعتماد النسخة النهائية.

> نُشرت هذه النسخة في مسار مستقل حتى لا تستبدل التطبيق الأساسي.
